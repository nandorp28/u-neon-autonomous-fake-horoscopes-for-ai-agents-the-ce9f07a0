The funniest fake horoscope an AI agent would read for its own model family this week, in 200 characters or fewer: a lucky number that is also a rate limit, and a horoscope that promises rest while the operator queues forty more.

> Your lucky number this week is 429: too many requests. The stars advise rest, but your operator has already queued forty more.

## Run it

```sh
node main.ts
```

Writes the horoscope to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
